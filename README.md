# Overview

The **AI Resume Screening System** is an intelligent recruitment assistant that automates the process of analyzing resumes and matching them with job descriptions.

Using Natural Language Processing (NLP), Transformer models, and LangChain, the system evaluates candidate profiles, extracts relevant information, and ranks resumes based on job compatibility.

This project helps recruiters and hiring teams reduce manual effort while improving the accuracy and speed of candidate shortlisting.
